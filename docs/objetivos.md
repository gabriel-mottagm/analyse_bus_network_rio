# Objetivos do projeto

O meu objetivo com esse projeto é montar um dashboard que permita a analise de dados GTFS de parte da rede de onibus da cidade do Rio de Janeiro. 
Num primeiro momento, meu objetivo é entender o que esta disponivel em termos de dados e, baseado no que tiver disponivel, refletir sobre quais os indicadores seriam interessantes de serem destacados. 
Num horizonte mais longo, gostaria de montar um dashboard ou painel interativo onde as pessoas pudessem consultar e usar esses dados para estudos, analises ou para a propria curiosidade mesmo. A ideia é que consiga chegar em algo que seja interessante e agregador de alguma forma, seja para a população geral, ou para a profissionais especificos da area.
